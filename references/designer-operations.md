# 设计器运维

> **证据状态**：文档推导（产品功能描述） · 已验证（部署 / 配置实测项） · 待确认（无后台凭据，未运行时核实） · 不适用。
> **知识包性质**：版本化运维知识包，非 AI 可执行 Skill；GDMP 运行时无 AI Agent / Skill 加载器，不得宣称 AI 执行。
> **变更基线**：生产默认只读；变更须审批；先 dry-run / 测试环境验证；数据库与应用回滚分别制定、不得默认互逆。
> **证据来源**：`audit/gdmp-module-inventory.md`、`gdmp-skill-runtime-audit.md`；`content/product/application-builder/`、`content/product/architecture/`。

## 1 设计器能力（文档推导 → 运行时待确认）
- 四大画布：页面画布（门户 / 工作台 / 业务页面）、APP 画布（移动审批 / 现场采集）、报表画布（中国式 / 填报 / 汇总）、大屏画布（驾驶舱 / 监测）。
- 应用构建链路：数据模型（字段 / 类型 / 校验）→ 表单页面 → 列表与报表 → 门户与工作台 → 流程与权限 → 发布（PC + 移动端）。
- 配置项：必填 / 长度 / 格式 / 范围 / 跨字段联动；复杂规则交规则引擎或脚本扩展（Groovy 2.5.23 运行时支撑）。
- 应用生命周期：创建 → 设计 → 页面 / 数据模型 / 表单 → 预览 → 发布 → 版本 / 回滚（详见 application-lifecycle）。

## 2 运维视角的变更治理
- 设计器中的页面 / 模型 / 表单 / 变量 / 脚本调整属于**配置变更**，等同上线变更：须审批、先在测试 / DEV 环境验证、记录版本号与变更说明。
- 配置迁移：平台提供 UI 配置、变量、角色 / 权限、脚本的整体迁移功能（文档指向《平台配置迁移操作说明》）；迁移后须冒烟验证（详见 migration-guide）。
- 发布后执行健康检查与关键业务冒烟；异常时按预案回滚应用或数据库，**二者不可默认互逆**。
- 应用元数据 / 表单配置存于数据库；手工改库可能与 `GdmpTableMigrate` 自动迁移冲突（详见 database-operations）。

## 3 已知坑位（已验证 / 文档记录）
- 迁移 pkg 包后样式未更新、日志 `值太长了(128)`：扩展 `t_sys_config.app_to_logon_pic` 从 128 到 4000 后重导（SQL 见 database-operations / troubleshooting）。
- 升级后老系统表格不显示复选框：文档称需在 Mongo 库中跑脚本；具体脚本内容**待确认**（文档未给出）。
- 前端资源更新涉及删除 `webapps/ROOT` 下静态资源目录；生产执行前须备份并审批（详见 troubleshooting / frontend 运维原文）。

## 4 AI 相关功能的正确解读（决定性）
- 文档「AI 能力」（自动写作、智能问答、标题 / 报告生成、NL2SQL、OCR 等）是**业务功能**，不是 Agent Skill Runtime。
- 设计器中不存在 Skill 管理 / Agent 编排页面证据；WAR 无 ai-agent / mcp / skill / llm / vector / embedding 组件。
- **不得**把知识包中的 SKILL.md / references 当作可被设计器或 AI 执行的内容；本包仅供人工查阅。执行能力未启用 / 受阻。

## 5 纪律
- 只读查看配置与预览为默认；任何保存 / 发布 / 迁移须审批 + dry-run。
- 运行时逐项能力核实需产品后台凭据，当前**待确认**。
