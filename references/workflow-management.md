# 工作流管理

> **证据状态**：文档推导（流程引擎功能描述） · 已验证（WAR 组件 / 配置实测） · 待确认（流程实例运行时 / 后台凭据） · 不适用。
> **知识包性质**：版本化运维知识包，非 AI 可执行 Skill；GDMP 无 AI Agent / Skill 运行时，不得宣称 AI 执行。
> **变更基线**：生产默认只读；变更须审批；先 dry-run / 测试环境验证；数据库与应用回滚分别制定、不得默认互逆。
> **证据来源**：`audit/gdmp-data-architecture.md`、`gdmp-risk-register.md`；`content/product/workflow/`；`content/docs/ops-reference/config/`。

## 1 引擎能力（文档推导 → 待确认）
- 可视化流程设计：条件分支、会签、或签、抄送、回退（指定节点 / 上一步 / 发起人）、子流程、加签 / 转办、超时提醒、节点前后业务动作。
- 文档称内置 10 大类、40 余种功能组件；流程发起可由表单 / 接口 / 定时触发；审批人可按用户、角色、部门、岗位、上级或表单字段动态解析。
- 流程范畴：设计、引擎、实例、节点、调度、异常、部署、版本（文档站模块清单）；运行留痕支撑审计与复盘。
- 实际流程定义 / 实例数量、节点健壮性未运行时核实 → **待确认**。

## 2 运行时依赖（已验证 / 配置实测）
- 流程状态与实例数据存于**数据库**：升级 / 回滚必须分开制定 DB 与应用方案，不得默认互逆（R7）。
- JMS 消息：`jms.workflow.command.queue=workflow.command.queue` 等队列（配置示例）；ActiveMQ 5.16.8 实测。
- 调度：Quartz 2.3.2，`GDMP_QUARTZ_Worker-*` 线程；`scheduler.properties` 的 `threadCount=10`、`RAMJobStore`。
- 集群：Hazelcast 3.12.13 基于 `gdmp.cluster.*`（默认 `gdmp.cluster.enabled=false`，端口 7800）。
- 队列积压处置：定时脚本同步导致崩溃后脚本仍执行，文档处置为清理 ActiveMQ `scheduledTask.event.queue`（Hawtio `/admin/queues.jsp` Purge）；属变更操作，须审批 + 确认消息丢失影响。

## 3 升级与兼容性（风险 R6，高）
- 升级风险明确包含历史**流程兼容性**：老流程定义 / 运行实例在新版本可能出现节点解析或状态异常。
- 升级前：盘点流程定义与在途实例版本、备份 DB 与应用配置、在测试环境验证关键流程；低峰窗口发布并冒烟。
- 在途实例降级尤其敏感：DB 中流程状态与应用代码版本须配套处理，**禁止默认认为回滚应用即可回滚流程数据**。

## 4 AI 相关表述边界
- 文档「流程智能推荐 / 场景智能化」属业务功能描述，不是 Agent Skill Runtime。
- 不得把知识包内容作为流程节点可执行技能；执行能力未启用 / 受阻。

## 5 操作纪律
- 默认只读查看流程定义 / 实例 / 日志；流程部署、版本切换、节点修复、队列清理须审批 + dry-run。
- 任何异常处置先备份相关表 / 队列快照，记录变更说明与回滚预案。
